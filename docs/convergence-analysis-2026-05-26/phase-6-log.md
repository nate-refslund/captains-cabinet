## Delivered

### 6.1 — Stack detector (`framework/products/stack_detector.py`)

Heuristic, file-based, no AST, no network, no language servers. Detects six dimensions across 30+ technologies:

- **Languages:** python, typescript, javascript, go, rust, ruby, java, php, elixir, swift, kotlin, csharp, dart, scala (14 supported)
- **Frameworks:** nextjs, nuxt, remix, astro, sveltekit, vite, django, rails, phoenix, laravel, react, vue, expressjs, nestjs, fastify, svelte, angular, fastapi, flask (19 supported)
- **Test runners:** pytest, vitest, jest, mocha, playwright, cypress
- **Databases:** postgres, redis, mongodb, mysql, sqlite (inferred from compose / env / config / file presence)
- **Deploy targets:** vercel, netlify, railway, render, fly.io, heroku, docker, kubernetes
- **CI providers:** github-actions, gitlab-ci, circleci, travis, buildkite, jenkins

Detection rules are simple `(slug, [filenames or globs])` tuples + a few file-content substring matches for package.json / pyproject.toml. Re-runnable; idempotent.

CLI: `python3 -m framework.products.stack_detector <repo> [--json]`.

### 6.2 — Bootstrap script (`cabinet/scripts/bootstrap-project.sh`)

Four-step flow:

1. `git clone --depth 50` (or `git pull` if directory exists — idempotent)
2. Run stack detector → JSON metadata
3. Generate `instance/config/projects/<slug>.yml` from `_template.yml`:
   - Patches `project_name`, `project_slug`, `github_repo` (inferred from URL), `workspace_path`
   - Defaults `tasks.system` to `github-issues` with the same repo (since `gh` CLI is the lowest-friction adapter)
   - Always overwrites `product_metadata` block (re-runs refresh detection)
   - **Preserves Captain-set fields** if YAML already exists
4. Prints Captain-facing exploration summary + next-step prompt

GitHub repo URL parser handles both `https://github.com/owner/repo.git` and `git@github.com:owner/repo.git` forms.

Slug validation: kebab-case, 1-32 chars, starts with letter/digit (mirrors `lib/triggers.sh` FW-073 rule).

Workspace default: `~/work/projects/<slug>/` (overridable via `--workspace DIR`).

### 6.3 — Project YAML template extended

- **`product_metadata:` block** — six list fields + `detected_at` timestamp; autogenerated by bootstrap, overridable by Captain
