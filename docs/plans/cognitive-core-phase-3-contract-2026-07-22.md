### 5.2 The transition function — one ORDERED, TOTAL state machine, derived at compile

*(Rewritten wholesale — resolves blockers C-B2 + A-B1 and majors A-M2, C-M3, C-M8. Nothing below keys on belief `kind`: consequence beliefs ARE kind `observation` (`adapters.py` `_CONSEQUENCE_KIND = "observation"`), so kind cannot discriminate observation from intervention evidence.)*

**Definitions, evaluated over an edge's bound views at the build cutoff (all computed from SERVED bytes — `BeliefView.value` carries the full claim, `query.py:191`; no fidelity import, §6.4):**

- **admissible(b):** the binding resolves in its subject's `as_of` closure, `subject_key` ∈ `admissible_subjects`, and the view is not `source_purged` (purged views are neither support nor refutation — visible in lineage, inert in every predicate below).
- **verified-join(b):** b is a consequence-stream view (`provenance.stream_rank == 1`) AND (i) the recorder digest of the claim's own `(actor, action, subject, ts)` identity tuple equals the `<identity-digest>` suffix of the view's `subject_key` — recomputed by the graph from claim bytes, so a claim that is not the row its subject names is a structural build failure — AND (ii) the claim's `(actor, action, subject)` matches the source intervention node's adapter-pinned `join_spec` (§4.1). **The join is machine-checked, never merely declared** (attack C-M3b); `assumptions` additionally declare the residual confounding honestly (§4.2) but verify nothing.
- **human-confirm(b):** admissible(b) ∧ verified-join(b) ∧ `claim.review.verdict == "confirmed"` ∧ **`claim.review.source == "verdict_human"`**. This is the ONLY promotion fuel — and "human" means ANY human's verdict: the Captain's or another person's, incl. verdicts surfaced via internal/external comms (Captain resolution 2026-07-22); never a machine or LLM. The discriminator is pinned to the consequence domain's own vocabulary (`consequence.py:126` `_REVIEW_SOURCES = {"verdict_human", "verdict_judge", "system", "verdict_gate"}`) and its fail-closed doctrine (`:110-125`): **absent `review`, absent `source`, or any source ≠ `verdict_human` — including `verdict_judge` (LLM) and `verdict_gate` (machine) — is promotion-INERT, fail-closed.** A judge's or gate's confident confirm can never mint `intervention_supported` (attack C-B2). Drift tripwire: §3 consequence row.
- **human-wrong(b):** admissible(b) ∧ verified-join(b) ∧ `claim.review.verdict == "wrong"` ∧ `claim.review.source == "verdict_human"`. The ONLY refutation fuel — `falsified` carries the SAME evidence-quality bar as promotion (attack C-M8: refutation-certainty is as manufacturable as confirmation-certainty; the Captain-facing word "refuted" earns the same gate as "tested"). Domain symmetry note: the consequence domain lets wrong-from-ANY-source demote graduation cells (`consequence.py:121`) — the graph mirrors that as a CAP, not a refutation: see machine-contested below.
- **machine-contested(b):** admissible(b) ∧ verified-join(b) ∧ `claim.review.verdict == "wrong"` ∧ `source ≠ "verdict_human"` (or absent). Demotion-grade, never refutation-grade.
- **direction-contradicting(b) / direction-supporting(b):** admissible(b) ∧ the adapter-pinned reading of the claim's movement on `dimension` is opposite / consistent-or-neutral w.r.t. the edge's `expected_effect` (§4.2). Per-adapter derivations are pinned in the §12.2 step-3 exhaustive fixture — never implementer-invented.

**The function — first matching rule wins (explicit total precedence P1 > P2 > P3 > P4 > P5 > P6); every edge with ≥0 bindings lands in exactly one rule:**

| # | condition | derived state |
|---|---|---|
| P1 | any bound view carries a non-empty `conflict_set` (`query.py:269-286`), OR human-confirm AND human-wrong bindings coexist (two human verdicts disagreeing is contradicted ground) | `hypothesized`, flagged `contested` — certainty is never manufactured over contradicted ground, in either direction (SIM-2) |
| P2 | ≥1 human-wrong binding (and P1 did not match) | `falsified` |
| P3 | ≥1 human-confirm binding ∧ edge `assumptions` non-empty (and P1/P2 did not match) | `intervention_supported` — reachable by EXACTLY this rule; the triple is (a) human-confirm (verdict + source discriminator), (b) verified-join (mechanical), (c) declared assumptions |
| P4 | ≥1 direction-contradicting or machine-contested binding | `hypothesized`, flagged `direction_contested` — observation and machine judgment can WEAKEN an edge back to hypothesis but can never mint `falsified` (the mirror of "observation cannot mark an intervention effective", :108) |
