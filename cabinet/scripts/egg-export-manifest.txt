# egg-export-manifest.txt — THE egg packaging manifest (fresh-cut export rules).
# =============================================================================
# Consumed by cabinet/scripts/egg-export.sh, which cuts a clean tree from git
# HEAD (never the working tree, never git history — history carries personal/
# employer data and the public artifact is NEVER this repo flipped) and then
# applies these directives IN ORDER to the export copy ONLY. The source
# checkout is strictly read-only to the exporter.
#
# Grammar (one directive per line; '#' starts a comment; blank lines ignored):
#   delete <glob>            remove matching paths from the export
#                            (single-level globs only — no '**'; absent = no-op)
#   delete-name <basename>   remove every path with this basename, recursively
#   transform <name>         run the named scripted transform in egg-export.sh
#   expect-present <path>    verify: path must exist in the final export
#   expect-absent <glob>     verify: glob must match nothing in the final export
#   expect-absent-name <basename>  verify: no path with this basename anywhere
#
# Every rule cites its row in docs/plans/operative-egg-ledger-2026-07-07.yml.
# R116 PROVENANCE NOTE (2026-07-10, PC-C): the R116 row's gate reads
# "packaging manifest exists listing every interface file -> header-only rule"
# and the row is marked done — but no such manifest artifact existed anywhere
# in the repo (full-text search: the only mentions were the ledger row and the
# plan row themselves). THIS file is that manifest, authored now.
#
# STRUCTURAL BASELINE (no directive needed — cited for completeness):
#   R088  cabinet/dashboard/{node_modules,.next} + channels node_modules are
#         untracked; `git archive HEAD` ships tracked files only. Defensive
#         delete-name below anyway.
#   .gitignore:177-196  LimeZu world assets, world-aesthetic corpus/goldens
#         images, and judge runs are gitignored (only the sha manifests are
#         tracked) — structurally excluded by the archive cut; verified by the
#         expect-absent rules at the bottom.
#   cabinet/fixtures/testburg/  SHIPS — it is the synthetic public demo estate
#         (leak-audited by cabinet/scripts/tests/test_testburg_fixture.py).
