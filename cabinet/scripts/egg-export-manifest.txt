# HEAD (never the working tree, never git history — history carries personal/
# employer data and the public artifact is NEVER this repo flipped) and then
# applies these directives IN ORDER to the export copy ONLY. The source
# checkout is strictly read-only to the exporter.
#
# Grammar (one directive per line; '#' starts a comment; blank lines ignored):
#   delete <glob>            remove matching paths from the export
#                            (single-level globs only — no '**'; absent = no-op)
#   delete-name <basename>   remove every path with this basename, recursively
#   transform <name>         run the named scripted transform in egg-export.sh
#   expect-present <path>    verify: path must exist in the final export
#   expect-absent <glob>     verify: glob must match nothing in the final export
#   expect-absent-name <basename>  verify: no path with this basename anywhere
#
# Every rule cites its row in docs/plans/operative-egg-ledger-2026-07-07.yml.
