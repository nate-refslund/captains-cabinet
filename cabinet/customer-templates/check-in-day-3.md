# Check-in — Day 3 (CoS Telegram Pulse, ~5min)

Per Spec 053 v4 Stage 6 cadence. **CoS-routed** via the customer's CoS Telegram thread. Day 3 post-install. Goal: light usage check + first NPS-light pulse + spend-trend sanity. This is the earliest quantified retention read — it feeds the validation gate's NPS health indicator.

## Pre-send (3min)

CoS pulls from audit log + dashboard:
- **Usage:** how many DMs across days 1-3? Which officers engaged? Single-officer or multi?
- **Spend trend:** 3-day cost trajectory. On pace for the tier, or running hot toward the $50/day cap?
- **Day-1 flag:** was there a silent-after-silent or blocker flag carried forward?

## Message

> "Hey {{customer_first_name}} — quick day-3 pulse. How's it feeling so far, on a scale of 1-5? And what's the one thing that'd make it more useful this week?"

Keep it genuinely quick. Day 3 is a pulse, not a call. The 1-5 number is the point — it's the first NPS-light datapoint and the leading signal for the Day-7 / Day-30 trajectory.

## Follow-on by score

**4-5 (healthy):**
> "Love it. {{reference something specific they've used}} — want a suggestion for something to try before our day-7 call?"

Offer one concrete next-thing matched to their stated use case. Plant the seed for a value-moment by Day 7.

**3 (neutral — the watch zone):**
> "Fair. What's the gap between 'fine' and 'I'd miss this if it disappeared'? That's exactly what I want to close before day 7."

A 3 at Day 3 is the make-or-break read. Surface the specific gap; route to the right officer to close it this week. Note for Day-7 Captain prep.

**1-2 (red — escalate):**
> "Thanks for the honesty — that's more useful than a polite 4. Can I get 5 minutes to understand what's not landing? I'd rather fix it now than at day 30."

Per Spec 053 fold I6 + Day-7 off-track rule: NPS-light ≤3 (and especially ≤2) triggers early escalation. CoS notifies Captain same day; Captain may pull the Day-7 call earlier or add a Day-5 touch.

## Listen for

- **Cost anxiety** ("am I burning money?") → walk through dashboard live: 3-day spend, cap-remaining. The audience-psychology finding: granular-metering anxiety erodes trust. Reassure with the predictable-bundle framing — the $50/day cap is a safety ceiling, not a meter they're racing.
- **Single-officer usage** → nudge toward a second officer matched to their use case. Multi-officer engagement is the depth signal that separates "active exec layer" from "paid chatbot."
- **"Replies aren't my voice"** → officers adapt; CoS can pin tone. Note for CTO if specific.
- **Silence (no reply to the pulse)** → second silent signal after Day-1. Escalate to Captain for a personal Day-4/5 nudge — two silent touches is a churn precursor.

## CoS post-send (within 30min)

- Log Day-3 result to Library Customer-Success Space: NPS-light score (1-5), usage depth (# officers, # DMs), spend trend, stated gap-to-close.
- Score ≤3 → notify Captain + flag Day-7 prep with the specific gap.
- Single-officer + low DMs → note usage-depth watch for Day-7 optimization push.
- Cost-anxiety surfaced → notify CTO for Spec 051 routing-efficiency check + note for Day-7 dashboard walkthrough.

## Captain-time-budget compliance (Spec 053 v4 AC #13)

Day-3 is CoS-routed → ~0min Captain time at baseline. Captain pulled in only on score ≤3 or second-silent escalation.
